## Contributing

Interested in contributing to Artemis? Here's how:

1. **Report issues** — Found a bug or have a suggestion? Open an issue.
2. **Improve docs** — See something unclear? Submit a PR.
3. **Add examples** — Real-world use cases help everyone.
4. **Build tools** — Create new tools and share them.

---

## Philosophy

Every future topic will follow the same rule:

> **Concept first, code second**

We explain *why* things exist before showing *how* they work. This ensures you understand the principles, not just the implementation.
