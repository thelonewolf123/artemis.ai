# Chapter 1: Talking to LLMs

In the previous chapter, we learned that an LLM is fundamentally a **token prediction engine**. But an important question still remains:

> **How do we actually talk to an LLM from our code?**

This chapter bridges concepts to implementation.

## What You'll Learn

By the end of this chapter, you'll understand:

- Where LLMs actually run (hint: not on your device)
- How to communicate with LLMs through HTTP APIs
- What API keys are and why they're important
- How the chat-completion format works
- How to call an LLM from Python
- How **tool calling** enables agents to take real actions

## Why This Matters

This chapter teaches you the foundational patterns that all agentic systems build upon:

- API communication
- Message formatting
- Tool-based interactions

Once you understand these patterns, everything else becomes clearer.
