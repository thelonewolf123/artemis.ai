# Artemis AI

**A Practical Guide to Building Agentic AI Systems**

Artemis is a **learning-first AI project** focused on understanding how modern **Large Language Models (LLMs)** can be composed into real, extensible, and controllable **agentic AI systems**.

This documentation is designed as:

- **A book you can read** - Concepts explained from first principles
- **A system you can run** - Working code you can experiment with

Rather than hiding complexity behind frameworks, Artemis exposes the core building blocks behind agentic systems step by step.

---

## Why Artemis?

Most LLM tutorials jump straight to frameworks. Artemis does the opposite.

It starts by answering:

- What an LLM actually is
- How token prediction works
- How models are accessed over APIs
- How tools, memory, and control flow emerge naturally

Only then does it move toward **agents**.

---

## What You'll Build

By the end of this guide, you'll understand how to create a fully capable **personal AI assistant** with support for:

- Natural conversational querying
- Tool extensibility (weather, search, and more)
- Long-term memory storage
- Multi-user support via Telegram
- Persistent conversation state
- Context window management

Each capability is introduced **incrementally**, not magically.
